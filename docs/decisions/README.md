# Architecture Decision Records (ADRs)

Este diretório contém as Architecture Decision Records da plataforma Terus.

## ADRs Aprovados

- **ADR-001** - Monorepo com Turborepo
- **ADR-002** - Next.js 14 com App Router
- **ADR-003** - FastAPI com Python
- **ADR-004** - Schema-per-tenant no PostgreSQL
- **ADR-005** - HashiCorp Vault para Credenciais de Cliente
- **ADR-006** - Celery + Redis para Filas
- **ADR-007** - D4Sign para Contratos Digitais
- **ADR-008** - Cloudflare para CDN, WAF e DNS
- **ADR-009** - Plausible para analytics do site

## ADRs Propostos (aguardam aprovação)

- **ADR-010** - Self Onboarding 2.0: jornada de aquisição persistida no backend
- **ADR-011** - E2E com Playwright sem nova dependência de runtime
- **ADR-012** - Nova experiência institucional em apps/site, isolada da LP

## Template

Para criar um novo ADR, siga o template definido em `PROJECT_RULES.md`, seção 16.
